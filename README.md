# Гамлет XXI века — тренажёр критического мышления

Веб-игра для занятия в аудитории. Компьютер с проектором — общее игровое поле,
у игроков — телефоны.

## Режимы

| Режим | Что нужно | Как играют |
|---|---|---|
| **Только ведущий** | только браузер | Команды (1–4) ходят по очереди и обсуждают вслух, кнопки на общем экране нажимает ведущий |
| **Ведущий + индивидуально** | сервер из этой папки | Каждый играет со своего телефона. Все получают одну карточку раунда, проектор показывает прогресс, ответы и таблицу лидеров |
| **Ведущий + команды** | сервер из этой папки | 2–4 команды. Участники заходят с телефонов в свою команду, капитан нажимает кнопки, остальные видят экран команды |

В любом режиме по QR-коду открывается справочник детектива: правила, «Бестиарий ошибок», искажения, формула шкалы и личный журнал.

## Файлы

- `index.html` — вся игра: экран проектора, телефон и справочник.
- `logic.js` — данные и правила игры. Их использует сервер, и эти же правила встроены в `index.html`.
- `server.js` — сервер: Node.js без внешних зависимостей.

## Запуск

Нужен Node.js 18 или новее.

```bash
cd gamlet21
node server.js                 # порт 8080
PORT=3000 node server.js       # другой порт
```

Откройте `http://ваш-сервер:8080` на компьютере с проектором.

### Timeweb Cloud Apps

«Apps» → «Создать» → Backend, Node.js → репозиторий с этой папкой.
Команда сборки — пустая, команда запуска — `npm start`. Порт берётся из переменной `PORT`.
Новый деплой перезапускает сервер и завершает текущие игры — не обновляйте приложение во время занятия.

### Постоянная работа (systemd)

`/etc/systemd/system/gamlet21.service`:

```ini
[Unit]
Description=Gamlet XXI game server
After=network.target

[Service]
WorkingDirectory=/opt/gamlet21
ExecStart=/usr/bin/node server.js
Environment=PORT=8080
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload && sudo systemctl enable --now gamlet21
```

### Через nginx (рекомендуется, с HTTPS)

Обновления на телефоны идут через Server-Sent Events, поэтому для `/api/stream` нужно выключить буферизацию:

```nginx
server {
    server_name game.example.ru;

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header Connection "";
        proxy_buffering off;
        proxy_cache off;
        proxy_read_timeout 1h;
    }
}
```

HTTPS можно получить через `certbot --nginx`. Без HTTPS игра тоже работает.

## Как провести занятие

1. На компьютере с проектором откройте игру и выберите режим.
2. В онлайн-режимах нажмите «Создать комнату»: на экране появятся QR-код и код комнаты.
3. Игроки сканируют QR, вводят имя (и выбирают команду) и ждут старта.
4. «Начать игру». Пока идёт раунд, проектор показывает, кто на какой зоне. Можно включить таймер.
5. «Показать ответы» — разбор карточки: верный ответ, первоисточник, как ответила группа, таблица.
6. После 5 раундов — закрытие Дела на телефонах, затем «Подвести итоги» и общий дебрифинг.

## Ограничения

- Комнаты хранятся в памяти сервера: перезапуск сервера завершает текущие игры.
- В комнате до 80 участников, на сервере до 200 комнат одновременно. Пустые комнаты удаляются через 12 часов.
- Хранятся только введённые имена и ходы игры — до перезапуска сервера.
- Шрифты загружаются с Google Fonts. Без интернета игра работает со стандартными шрифтами.

QR-коды строит библиотека qrcode-generator (Kazuhiko Arase, лицензия MIT). Она встроена в `index.html`.
